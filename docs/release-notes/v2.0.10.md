## 2.0.10

This release closes the native and external subagent failure paths end to end.

- Native worker bootstraps remain queued until the authenticated companion browser is actually connected, so a restart cannot consume the worker redemption window before any page can receive the command.
- Fresh worker conversations bind as soon as ChatGPT exposes exact route/turn evidence, avoiding background-tab timer clamping after native Send.
- The external `chat-on-steroids-subagent` owner profile now uses the dedicated `oracle-browser` transport with persistent attach approval, exact connector selection evidence and frozen conversation receipts.
- The legacy Electron external-job path fails closed if a job requests a browser identity different from the already-running app, rather than changing process-wide browser settings underneath native workers.

**Reload the matching companion extension and refresh the Chat On Steroids connectors in ChatGPT after updating.**
